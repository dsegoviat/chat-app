# Domain docs

This repository is configured as a **single-context** project.

## Layout

- Domain context: `CONTEXT.md` at repository root
- Architectural decisions: `docs/adr/`

## Consumer rules for skills

- Read `CONTEXT.md` first to align with domain language and boundaries.
- Read relevant ADRs in `docs/adr/` before proposing architecture changes.
- If `CONTEXT.md` or ADRs are missing, proceed with best effort and note assumptions explicitly in outputs.
- Treat `CONTEXT-MAP.md` as not in use unless this file is updated to multi-context.
